# Нэр томьёоны тайлбар

Англи нэршлийг эхний хэрэглээнд монгол тайлбартай өгч, цааш нэг утгаар хэрэглэнэ. Кодын identifier, URL, schema field, HTTP method, enum утгыг орчуулахгүй.

| Нэршил | Энэ төслийн хэрэглээ | Андуурахгүй байх зүйл |
|---|---|---|
| Documentation | Баримтжуулалт; үр дүн нь баримт бичиг | Кодын comment-оор хязгаарлагдахгүй |
| Public API | Гаднаас ашиглуулахаар зарласан интерфейс | Заавал интернэтэд нийтэд нээлттэй endpoint биш |
| Endpoint / operation | Зам / HTTP method + зам | Нэг зам дахь POST, GET нь хоёр operation |
| SRS | Програм хангамжийн шаардлагын тодорхойлолт | Хэрэгжилтийн гарын авлага эсвэл architecture design биш |
| FR / NFR | Функциональ / функциональ бус шаардлага | ID-г өөр агуулгад дахин ашиглахгүй |
| Acceptance criterion | Хүлээн авах шалгуур | Тест ажиллуулсан нотолгоо биш |
| Verification | Test, Inspection, Analysis-аар шаардлагыг шалгах | Файл байгааг runtime баталгаа гэж үзэхгүй |
| Traceability | Хэрэгцээ → шаардлага → бүрэлдэхүүн → шалгалтын мөрдөх холбоо | Зөвхөн ID-ийн жагсаалт биш |
| Persona | Зорилтот уншигчийн төлөөлөх дүр | Зохиосон persona нь бодит ярилцлага биш |
| End user / end-end user | Баримт ашиглах хөгжүүлэгч / системийн эцсийн хэрэглэгч | API developer ба хоол захиалагчийн зорилго ялгаатай |
| ADR / MADR | Архитектурын шийдвэрийн тэмдэглэл / Markdown бүтэц | Proposed нь Accepted гэсэн үг биш |
| C4 container | Deploy/run хийгдэх програм эсвэл өгөгдлийн сангийн хил | Заавал Docker container биш |
| Contract | Оролт, гаралт, алдаа, authentication-ийн гэрээ | Mock-ийн санамсаргүй payload биш |
| Mock / fixture | Туршилтын орлуулалт / тогтмол өгөгдөл | Production service, бодит төлбөр биш |
| Idempotency key | Давтан нэг хүсэлтээс нэмэлт order үүсгэхгүй байх түлхүүр | Өөр payload-г ижил key-ээр зөвшөөрөхгүй |
| TTL | Хадгалах хугацааны хязгаар | W06 OrderService-д хэрэгжээгүй |
| Ownership | Захиалга хэрэглэгчид харьяалагдах нөхцөл | owner_id дангаараа authentication биш |
| Authentication / authorization | Хэн болохыг тогтоох / эрхийг шалгах | Bearer scheme нь жинхэнэ JWT implementation биш |
| Docstring | Module/class/callable-ийн бүтэцтэй тайлбар | Кодтой зөрсөн тайлбар хүчинтэй баталгаа биш |
| Doctest | Docstring-ийн жишээг ажиллуулж хариутай тулгах | Бүх unit/integration тестийг орлохгүй |
| Hallucination / ghost API | AI-ийн баримтгүй мэдэгдэл / кодод байхгүй API | Negative fixture-г model-ийн бодит алдаа гэж тайлагнахгүй |
| Technical debt | Шийдвэрлэх ёстой хязгаар ба засварын ажил | Хуурамч issue ID-гаар хаахгүй |
| CI/CD / artifact | Автомат шалгалт ба нийлүүлэлт / үүссэн файл | Локал success нь hosted success биш |
| Pending / Confirmed / Cancelled | Хүлээгдэж буй / баталгаажсан / цуцлагдсан төлөв | Enum-ийн бичлэгийг өөрчлөхгүй |
| LCP | Largest Contentful Paint; дэлгэцийн гол агуулга харагдах хугацааны хэмжүүр | API response latency-тай адил биш |
| p75 / p95 | Хэмжилтийн 75% / 95% нь тухайн утгаас ихгүй байх percentile | Дундаж утга биш; орчин ба sample size-ийг тэмдэглэнэ |
| Schema | Өгөгдлийн бүтэц, төрөл, заавал байх талбарын дүрэм | Нэг example бүх valid/invalid утгыг батлахгүй |
| Snapshot | Тухайн агшны өгөгдлийн тусгаар хуулбар | Өөрчлөхөд store автоматаар өөрчлөгдөх live object биш |
| Proposed / Accepted | Санал болгосон / review-ээр зөвшөөрсөн шийдвэр | Review хийгээгүй байхад төлөвийг дэвшүүлэхгүй |

“Хурдан”, “найдвартай”, “хялбар” гэх үгийг хэмжүүр эсвэл тодорхой зан үйлгүйгээр acceptance criterion болгохгүй.
