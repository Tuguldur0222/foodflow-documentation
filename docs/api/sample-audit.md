# Кодын жишээний чанарын үнэлгээ

Bhatti-ийн таван зарчмыг W05 handout-д тайлбарласан шалгуураар хэрэгжүүлэв.
Үнэлгээ нь энэ шинэчлэлд хийсэн өөрийн хяналт; багш, хэрэглэгч эсвэл хараат бус
шинжээчийн үнэлгээ биш. 5 нь тухайн сургалтын хэрэгцээг бүрэн хангасан, 4 нь
хэрэгжсэн боловч дурдсан хязгаар үлдсэн, 3 нь нэмэлт засвар шаардлагатай гэсэн утгатай.

Нийлбэр **184/200 = 92%**, таван онооны дундаж **4.6/5**.
Энэ нь handout-ийн ≥80% босгыг сургалтын локал хүрээнд хангана.

| Зарчим | Шалгасан нотолгоо | Үлдсэн хязгаар |
| --- | --- | --- |
| **Explained** — зорилго, оролт, нөхцөлийг тайлбарлах | Скриптийн module docstring, cURL хүсэлт бүрийн тайлбар, API README-ийн ажиллуулах дараалал. | FoodFlow-ийн таван үйлдэл нэг скриптэд багтсан; үйлдэл тус бүрийн тайлбарыг README-тэй хамт уншина. |
| **Concise** — шаардлагатай кодыг үлдээх | Python стандарт сан ашигласан; нэмэлт SDK, framework шаардаагүй. | Multipart-ийн CRLF, boundary, JSON хаягийн талбаруудыг бүрэн илэрхийлэхэд нэмэлт мөр шаардлагатай. |
| **Clear** — утгатай нэр, ойлгомжтой бүтэц | `payment_method`, `photo_bytes`, `subscription` зэрэг нэр; схемтэй ижил талбар, ижил том жижиг үсэг. | Нэршлийн өөрчлөлтийг API гэрээтэй хамт хянах шаардлагатай. |
| **Usable** — ажиллуулах боломжтой байх | Windows-д Python хувилбар; Bash орчинд cURL хувилбар; repo-д JPEG/WAV fixture; UE-5 гурван скриптийг subprocess-оор ажиллуулдаг тест. | FoodFlow дарааллыг дахин ажиллуулахын өмнө mock-ийг дахин асаана. |
| **Trustworthy** — хариуг сервертэй тулгах | Таван FoodFlow хариуг YAML-ийн response example болон schema-тай тулгана. Гурван Corg.ly скрипт локал HTTP сервертэй хүсэлт солилцож, буцсан JSON-ийг шалгана. | Бодит төлбөр, JWT, production сервер, амьтны дууны AI эсвэл webhook хүргэлтийг батлаагүй. Тиймээс 5 оноо өгөөгүй. |

`cart_101`, `food_id=7`, `FF-1024`, `corgi_98231` нь тодорхой, давтагдах боломжтой
сургалтын fixture. `einstein.jpg` болон `einstein_bark.wav`-ийн синтетик гарал
[өгөгдлийн тайлбарт](../../examples/data/README.md) бий. Кодын хүсэлтэд
`foo`, `bar` зэрэг утгагүй placeholder ашиглаагүй.

Үнэлгээг дахин шалгах:

```powershell
python -m unittest tests.test_openapi tests.test_mock_api -v
```

Эх сурвалжийн хүрээ: хавсаргасан *Sprint 05 Lab Instructions — OpenAPI 3.0 &
Bhatti Code Samples*, Bhatti-ийн зарчмын хүснэгт болон UE-5 даалгавар. Handout-д
дурдсан *Docs for Developers*, Ch. 5, pp. 83–99 номын бүтэн эхийг энэ repo-д
хавсаргаагүй тул номын эшлэлийг бие даан уншиж баталсан гэж мэдэгдээгүй.
