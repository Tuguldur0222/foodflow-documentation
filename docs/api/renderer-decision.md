# Swagger UI ба Redoc: 100 үгийн сонголтын тайлбар

Доорх үндсэн бичвэрийн үгийг хоосон зайгаар салгаж тоолов. Гарчиг, энэ тайлбар,
эх сурвалжийг 100 үгт оруулаагүй. Энэ нь хэмжилтийн тайлан бус, одоогийн
сургалтын хэрэглээнд зориулсан шийдвэр юм.

<!-- decision:start -->
FoodFlow-ийн API баримтжуулалтад Swagger UI болон Redoc-ийг зэрэг ашиглахаар сонгов. Swagger UI нь токен оруулж, хүсэлтийн биеийг өөрчлөн, HTTP хариуг шууд харах боломжтой тул хөгжүүлэгчийн туршилтад тохиромжтой. Redoc-ийн навигац, тайлбар, JSON жишээг зэрэгцүүлсэн бүтэц нь API гэрээг уншихад тустай. Хайлтын хурд болон уншихад зарцуулах хугацааг бодит хэрэглэгчээр хэмжээгүй учраас аль нэгийг илүү хурдан гэж дүгнээгүй. Хоёр харагдац нэг OpenAPI файлаас үүсэх тул мэдээллийн зөрүү багасна. Одоогийн туршилт локал mock серверт хамаарна. Нийтэд байршуулахдаа HTTPS, sandbox серверийн хүртээмж, браузерын хязгаарлалтыг шалгана. Дараагийн семинарт хөгжүүлэгчдээр ижил гурван даалгавар гүйцэтгүүлж, амжилтын хувь, хугацаа, ойлгомжгүй хэсгийг бүртгэн, сонголтоо дахин үнэлнэ. Үр дүнг GitHub-д хадгална.
<!-- decision:end -->

Хэрэгжүүлэлтийн үндэс: [Swagger UI installation](https://swagger.io/docs/open-source-tools/swagger-ui/usage/installation/),
[Redoc HTML deployment](https://github.com/Redocly/redoc/blob/main/docs/deployment/html.md).
