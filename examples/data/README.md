# Синтетик туршилтын өгөгдөл

| Файл | Үүсэл, зориулалт |
| --- | --- |
| `einstein.jpg` | 32 × 32 пикселийн хар, цагаан шатрын хээ. Фото upload-ийн multipart хүсэлтийг туршихаар үүсгэсэн; амьтны гэрэл зураг биш. |
| `einstein_bark.wav` | 8 kHz, mono, 16-bit PCM, 0.1 секундийн 440 Hz синус долгион. Audio upload-ийн байтыг туршихаар үүсгэсэн; нохойн хуцах дуу биш. |

Хоёр файлыг энэ төслийн `make_fixtures.py` үүсгэнэ. Хувийн мэдээлэл болон гаднын
зохиогчийн бүтээл агуулаагүй. `Einstein`, `corgi_98231` нэрийг W05 handout-ийн
зохиомол Corg.ly кейсийн нэршилтэй нийцүүлсэн. Файлын нэр нь өгөгдлийн бодит
агуулгыг төлөөлөхгүй тул кодын жишээ бүрд синтетик болохыг тайлбарлав.

Дахин үүсгэхэд Pillow хэрэгтэй; бэлэн файлуудтай жишээг ажиллуулахад нэмэлт сан
шаардахгүй:

```powershell
python -m pip install Pillow
python examples/data/make_fixtures.py
```
