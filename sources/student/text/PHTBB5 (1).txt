POST /v1/pets/upload-photo 
Эхний жишээ pet_id=corgi_98231 -ийн einstein.jpg файлыг multipart -аар илгээнэ. Сервер 201 ба зурагт хандах локал URL

"""UE-5 sample 1: upload Einstein's training image to the local Corg.ly mock.""" 
from pathlib import Path 
from urllib.request import Request, urlopen 
import json 
 
photo_bytes = (Path(__file__).parent / 'data/einstein.jpg').read_bytes() 
boundary = 'CorglyEinsteinPhotoBoundary' 
multipart_body = ( 
    f'--{boundary}\r\nContent-Disposition: form-data; name="pet_id"\r\n\r\ncorgi_98231\r\n' 
    f'--{boundary}\r\nContent-Disposition: form-data; name="photo"; filename="einstein.jpg"\r\n' 
    'Content-Type: image/jpeg\r\n\r\n' 
).encode() + photo_bytes + f'\r\n--{boundary}--\r\n'.encode() 
request = Request( 
    'http://127.0.0.1:8765/v1/pets/upload-photo', data=multipart_body, 
    headers={'Authorization':'Bearer demo-corgly-token', 
             'Content-Type':f'multipart/form-data; boundary={boundary}'}, 
    method='POST', 
) 
with urlopen(request) as response: 
    print(response.status, json.dumps(json.load(response), ensure_ascii=False)) 
Шалгалтын үр дүн: 201, pet_id=corgi_98231, status=uploaded. Энэ утга локал mock-ийн бодит хариунаас авсан.

"""UE-5 sample 2: upload a training WAV and read the local mock translation.""" 
from pathlib import Path 
from urllib.request import Request, urlopen 
import json 
 
audio_bytes = (Path(__file__).parent / 'data/einstein_bark.wav').read_bytes() 
request = Request( 
    'http://127.0.0.1:8765/v1/audio/translate-bark', data=audio_bytes, 
    headers={'Authorization':'Bearer demo-corgly-token','Content-Type':'audio/wav', 
             'X-Pet-Id':'corgi_98231','X-Target-Language':'en'}, 
    method='POST', 
) 
with urlopen(request) as response: 
    print(response.status, json.dumps(json.load(response), ensure_ascii=False)) 
Шалгалтын үр дүн: 200, pet_id=corgi_98231, language=en. Энэ утга локал mock-ийн бодит хариунаас авсан.

POST /v1/webhooks/subscribe 
Гурав дахь жишээ pet.activity үйл явдлын локал webhook URL -ийг бүртгэнэ. Mock 201 ба sub_corgi_1024 дугаар буцаана;

"""UE-5 sample 3: register a local receiver for pet.activity events.""" 
from urllib.request import Request, urlopen 
import json 
 
subscription = {'url':'http://127.0.0.1:8765/webhook-receiver','events':['pet.activity']} 
request = Request( 
    'http://127.0.0.1:8765/v1/webhooks/subscribe', 
    data=json.dumps(subscription).encode('utf-8'), 
    headers={'Authorization':'Bearer demo-corgly-token','Content-Type':'application/json'}, 
    method='POST', 
) 
with urlopen(request) as response: 
    print(response.status, json.dumps(json.load(response), ensure_ascii=False)) 
Шалгалтын үр дүн: 201, subscription_id=sub_corgi_1024, status=active. Энэ утга локал mock-ийн бодит хариунаас авсан.

Swagger UI ба Redoc 
Swagger UI-г багийн дотоод шалгалтад сонгов. Учир нь Try it out товчоор токен, хүсэлт, хариуг нэг дэлгэцээс туршиж болно. 
Энэ нь Анугийн API -г холбоход хэрэгтэй. Redoc нь гурван хэсэгтэй зохион байгуулалттай тул уншигч endpoint, тайлбар, 
жишээг зэрэг харахад эвтэйхэн. Олон endpoint дундаас хайж олох хугацааг бодит хэрэглэгчээр хэмжээгүй тул аль нь хурдан 
гэж дүгнэхгүй. Локал mock-ийн Swagger UI дээр турших урсгалыг, нийтэд унших хувилбарт Redoc -ийг санал болгов. Аль аль 
нь нэг openapi.yaml файлыг уншина. Жинхэнэ сервер болон нийтэд нээлттэй URL бэлэн болмогц хайлт, уншигдах байдал, Try 
it out-ийн үр дүнг хэрэглэгчээр шалгаж шийдвэрээ батална. Энэ шийдвэрийг дараагийн sprint-д дахин хянана 
Хоёр харагдац нэг public/openapi.yaml файлыг уншина. Локал mock асаалттай үед Swagger UI, Redoc гэсэн хоёр замаар орж 
болно. Static HTML нь CDN -ийн JS/CSS татдаг тул интернет холболт хэрэгтэй. Public хавтсыг нийтлэхэд хоёр HTML ба 
YAML-ыг хамтад нь байршуулна; одоогоор нийтэд нээлттэй URL -д байршуулж, браузерт харагдах байдлыг 
баталгаажуулаагүй. Try it out нь локал сервер асаалттай машин дээр ажиллана.
