3. US-6.2 — Sphinx болон GitLab CI/CD
docs/source/conf.py нь autodoc, napoleon өргөтгөлтэй. api.rst нь Python module-ийн public 
members-ийг авч, index.rst-д API холбоос оруулсан. .gitlab-ci.yml хоёр шаттай: тестийн шатанд 
W05/W06 unit, doctest; default branch дээр Pages шатанд requirements-docs.txt-аас Sphinx суулгаад 
sphinx-build -W --keep-going -b html docs/source public ажиллуулна. -W анхааруулгыг бүтэлгүй 
build болгоно. Pages-ийн publish: public болон artifact path нь нэг хавтаст заана. Repo-г GitLab-д 
оруулсны дараа project-ийн CI/CD Pages URL-г шалгаж баримтжуулах ёстой.
Орон нутгийн бодит туршилт: python -m sphinx -W -b html docs/source /tmp/foodflow-sphinx-
build → exit 1, No module named sphinx. pip install хийж үзэхэд орчны proxy Operation not 
permitted гэж буцсан. review/sphinx_build_log.txt-д команд ба үр дүн хадгалагдсан. Иймд zero-
warning Sphinx HTML, green GitLab pipeline, public Pages URL гурвыг DoD-д биелсэн гэж 
тооцоогүй. W05-ийн public/swagger.html нь өмнөх OpenAPI preview бөгөөд Sphinx-ийн үр дүн гэж 
үзэхгүй. GitLab CI-д package registry, runner, Pages тохируулгыг ажиллуулах бодит орчин хэрэгтэй.
