# Эх материалын бүртгэл

`manifest.json` нь хэрэглэгчийн өгсөн файлын нэр, хэмжээ, SHA-256-ыг хадгална.
Эх Word/PDF/YAML-ийг локал workspace-д хэвээр үлдээсэн. GitHub-ийн үндсэн
баримтжуулалт `docs/` доторх шинэчилсэн Markdown; handout-ийн бүтэн текстийг
нийтлэхийн оронд шаардлага, source index-ээр холбоно.

Давхардсан файл ижил hash-тай бол нэг агуулга. Manifest нь файлын гарал ба
хувилбарыг таних баримт; тухайн тайлангийн runtime claim-ийг батлахгүй.
